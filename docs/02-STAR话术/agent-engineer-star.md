## 追问应对

### Q: ReAct 模式是什么？和普通 Agent 有什么区别？

**A**: ReAct 是 Thought → Action → Observation 循环：
1. **Thought**：分析用户问题，决定是否需要调用工具
2. **Action**：选择合适的工具并执行
3. **Observation**：获取工具返回结果
4. **循环**：直到得出最终答案

和普通 Agent 的区别是，ReAct 有明确的思考过程，可以解释为什么选择某个工具，而不是直接给出答案。

### Q: RAG 检索的流程是什么？

**A**: RAG 分为三个阶段：
1. **索引阶段**：文档解析 → 分块 → 向量化 → 存入 Milvus
2. **检索阶段**：用户问题向量化 → Milvus 检索 Top-K → BM25 关键词检索 → RRF 融合
3. **生成阶段**：将检索结果作为上下文，调用大模型生成答案

### Q: 知识图谱在根因分析中怎么用？

**A**: 知识图谱存储服务拓扑关系：
1. **图查询**：从告警服务出发，遍历依赖链
2. **贝叶斯推理**：计算每个可能根因的概率
3. **排序**：按概率排序，选择最可能的根因

比如 order-service CPU 高，查到它依赖 payment-service，payment-service 今天有新部署，贝叶斯推理得出 P(部署引起|CPU高) = 0.54。

### Q: MiMo 大模型有什么优势？

**A**: MiMo 是小米推出的国产大模型：
1. **推理能力强**：在数学推理、代码生成等任务上表现优异
2. **延迟低**：国内部署，网络延迟低
3. **成本低**：相比 OpenAI，API 价格更便宜
4. **支持中文**：对中文理解更好

我们通过模型路由实现主备切换，MiMo 故障时自动降级到 OpenAI。
