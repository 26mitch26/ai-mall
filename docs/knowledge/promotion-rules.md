# AI-Mall 促销活动与优惠券规则

优惠券的领取：优惠券分为平台券与店铺券两类，可在优惠券中心、商品详情页与活动会场领取，每张券有明确的适用范围、使用门槛与有效期。同一用户对同一张券通常限领一张，部分活动券支持重复领取，具体以券面说明为准。领取后的优惠券会进入"我的-优惠券"列表，请留意到期时间，过期后自动失效且不可恢复。

优惠券的使用：单笔订单默认只能使用一张优惠券，平台券与店铺券不可叠加；特殊大促期间开放叠加的券会在券面标注"可叠加"。使用门槛按订单商品优惠后金额计算，运费不计入门槛。下单时系统会自动推荐可用优惠券，也可手动选择；已使用的优惠券在订单退款后按规则退回：整单退款且券未过期的原路退回，部分退款与过期券不退回。

限时购与满减：限时购商品在活动时段内按活动价销售，数量有限、售完即止，每人限购数量以商品页标注为准。限时购订单在支付前不锁定库存，建议尽快完成支付；超时未支付的订单将自动取消并释放库存。满减活动按订单金额档位自动扣减，与优惠券的叠加规则以活动页说明为准；跨店满减在购物车内合并结算时自动计算。

积分与成长值：订单完成后按实际支付金额返还积分，普通会员按一比一返还，银卡及以上会员享受一到两倍加速返还；积分可用于下单抵扣，一百积分抵扣一元，单笔订单最高抵扣订单金额的百分之二十。成长值仅用于会员等级计算，不参与抵扣。退货退款时，对应订单返还的积分与成长值将同步扣回；积分扣回后余额不足的会记录为负值，在后续订单返还中优先抵扣。

活动规则通用条款：同一用户、同一手机号、同一收货地址或同一支付账号均视为同一参与主体，平台有权对异常交易（批量下单、机器抢购、虚假收货信息等）取消订单并追回优惠。活动商品的价格、库存与赠品以提交订单时的页面信息为准，平台对活动规则拥有最终解释权，规则调整会提前在活动页公告。
