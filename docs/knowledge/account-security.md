# AI-Mall 会员账号与信息安全说明

账号注册与登录：会员账号支持手机号注册与登录，注册时需完成短信验证码校验。为保障账号安全，登录密码要求八位以上并包含字母与数字；连续五次输入错误密码账号将被临时锁定三十分钟，可通过短信验证码快速解锁。建议开启登录保护，开启后在陌生设备登录需要额外短信验证。

密码找回：忘记密码时，在登录页选择"忘记密码"，通过注册手机号接收验证码后重置。若手机号已停用，可联系人工客服并提供最近一笔订单的订单号、收货人姓名与下单时间进行身份核验，核验通过后协助更换绑定手机号。为保护账号安全，客服不会索要您的登录密码与短信验证码，任何索要验证码的行为均为诈骗。

信息安全与隐私：平台仅收集与交易履约必要的信息，包括收货人姓名、联系电话、收货地址与订单记录，用于配送、售后与发票开具。手机号、身份证号等敏感字段在数据库中加密存储，日志系统对敏感字段脱敏展示；跨系统传输使用加密通道。未经您授权，平台不会向第三方提供您的个人信息，法律法规另有规定的除外。

账号异常处理：如发现账号存在异地登录提醒、订单异常或余额变动，请立即修改密码并通过在线客服反馈，平台将冻结账号交易功能并协助核查。账号因违规行为（恶意刷单、虚假交易、发布违规内容）被限制的，可通过客服提交申诉，申诉处理周期为三到五个工作日。

账号注销：在"我的-设置"中可发起账号注销申请，注销前需结清未完成订单、退回未使用的优惠券与积分余额。注销申请提交后有七天冷静期，冷静期内登录账号即视为撤销申请；注销完成后，账号资料与个人信息将按隐私政策进行删除或匿名化处理，交易记录依据法律法规要求保留三年。
