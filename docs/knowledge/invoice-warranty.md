# AI-Mall 发票与保修服务说明

发票类型：平台支持开具电子普通发票与增值税专用发票。电子普通发票在订单完成后自动开具并发送至下单邮箱，也可在订单详情页手动申请重发；增值税专用发票需在提交订单时选择并填写完整的公司名称、纳税人识别号、开户行与账号、注册地址与电话，审核通过后三个工作日内开具并邮寄。

开票时间：订单支付完成后即可申请开票；订单发生退款时，发票将同步冲红作废。已开具的发票如需更换，请在开票后三十天内提交更换申请，注明更换原因并提供正确的抬头信息；跨月换开需要先作废原发票，周期约为三到五个工作日。

保修期限：手机、平板、笔记本等主机类商品自签收之日起提供十二个月官方保修；耳机、充电器、数据线等配件类商品提供六个月保修；电池等易损耗部件按厂商标准执行六个月的保修期。会员等级为银卡及以上的用户，主机类商品保修期在标准基础上延长三个月。保修期内因非人为原因出现的功能性故障，平台提供免费维修或换新服务。

保修流程：在订单详情页选择对应商品提交维修申请，说明故障现象并上传照片或视频；审核通过后按短信提示寄回商品，或前往品牌授权服务网点检测。维修周期一般为七到十五个工作日，维修完成后由平台寄回；维修期间同一商品不支持重复提交申请。寄修往返运费在保修期内由平台承担，保修期外由用户承担。

以下情形不在保修范围内：人为损坏（进液、摔损、私自拆机、非授权维修点拆修）、超出保修期限、无有效购买凭证、商品序列号被涂改或无法识别、以及不可抗力造成的损坏。保修期外的维修将按官方价目表收取材料费与人工费，维修前客服会先与您确认报价，确认后再进行维修；未确认报价的商品将在七日内原样寄回，不收取检测费用。
