# AI-Mall 商品验收与换货细则

收到包裹后请先在快递员在场时完成外观验收：核对外包装是否破损、封条是否完整、快递面单信息是否与订单一致。如外包装存在明显破损、浸水或二次封装的痕迹，建议当场拍照并拒收，包裹退回后平台会为您优先补发或全额退款，拒收产生的运费由平台承担。

签收后请在三日内完成开箱检查。开箱时建议录制完整视频，依次检查商品本体、配件、说明书与赠品是否齐全，核对型号、颜色、容量与下单信息是否一致。电子类商品需开机检查屏幕、摄像头、扬声器、充电接口等常用功能是否正常；服饰类商品需检查面料、走线、拉链与尺码标识。发现缺件或外观瑕疵的，请在订单详情页提交换货申请并上传照片，客服会在一个工作日内响应。

七天无理由退货以签收次日零点起算。退回商品需保持完好、吊牌未剪、不影响二次销售，配件与赠品需一并退回；食品、贴身衣物、定制类与已激活的数字化商品不支持无理由退货。十五天质量问题换货以签收之日起算：经检测确属质量问题（非人为损坏）的，平台提供同型号换新；同型号无货时可按原价退款或补差价更换其他型号。

换货流程：在订单详情页选择需要更换的商品与规格，提交换货原因与说明；审核通过后按短信提示寄回商品，平台签收并检测通过后寄出新品，往返运费均由平台承担。换货期间原订单金额不做变动，新商品的保修期自换货签收之日重新计算。若换货商品为促销购买且当前促销已结束，换货仍按原订单金额执行，不补收差价。

以下情形不支持换货：人为损坏（进液、摔损、私自拆机、非官方维修）、超出十五天期限、无法提供有效购买凭证、赠品单独申请换货、以及商品序列号与订单记录不一致的。对检测结果有异议的，可申请第三方检测机构复检，复检周期一般为五到七个工作日，复检结论为最终处理依据。
