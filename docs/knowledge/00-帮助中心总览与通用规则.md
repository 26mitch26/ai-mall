## 二、通用定义（全站统一口径）

为避免歧义，以下术语在所有政策文档中含义一致：

1. **签收**：以物流系统记录的「签收时间」为准。代收（驿站、快递柜、他人代签）视同本人签收；贵重商品（单价 ≥ 2000 元）可选择「开箱验货」服务，详见[物流配送政策](shipping-policy.md)。
2. **工作日**：指中国大陆法定工作日（周一至周五，不含法定节假日）。「小时级」时效按自然小时计算，不扣除夜间。
3. **自然日**：连续日历日，含周末与节假日。
4. **订单实付金额**：指买家实际支付的金额，不含平台补贴、不含运费（除非另有说明），含使用优惠券后的净额。
5. **商品完好 / 不影响二次销售**：指商品本体、配件、商标标识、吊牌齐全，未经穿着、洗涤、改装或非必要使用；「必要使用」指为确认品质与功能所做的合理查看（如试穿尺码、开机验机）。
6. **平台承担运费**：指由 AI-Mall 或对应入驻商家承担，买家无需垫付；如买家已垫付，按对应政策原路返还或与退款一并处理。
7. **银卡及以上**：会员等级达到银卡、金卡或钻石卡（成长值门槛见[会员权益规则](member-benefits.md)）。
8. **三包**：依据《部分商品修理更换退货责任规定》等法规，对列入目录的商品提供「包修、包换、包退」服务；具体期限以商品页面与[发票与保修服务](invoice-warranty.md)为准。

## 四、联系方式与服务时间

- **智能客服**：7×24 小时在线，支持退换货、物流、支付、发票等常见问题自助办理与工单提交。
- **人工客服**：每日 09:00–21:00（法定节假日另行公告），可在智能客服中一键转人工。
- **在线工单**：会员中心 → 我的订单 → 申请售后，系统自动派单并展示处理时间戳。
- **客服邮箱**：support@ai-mall.example（仅处理非紧急书面咨询，工单类请以 App 内提交为准）。
- **争议升级**：对处理结果有异议，可在工单内点击「申请平台介入」，详见[售后服务与工单规范](after-sale-process.md)第六节。

## 六、文档结构与分块（chunk）验证说明

本帮助中心文档按 **`policy_section` 分块策略**组织，便于验证分块效果：

1. **章节层级化**：每篇使用一致的 `## / ### / ####` 标题层级，分块以标题边界为软切分点，单块带标题上下文。
2. **规则-例外成对**：每条规则后紧跟「但／例外／不适用／然而」等限定，分块策略需保证**完整规则与对应例外共同出现在同一块**（验证指标：规则-例外共现率）。
3. **表格完整性**：运费表、时效表、保修表、违规处理表等连续表格行在分块时保持完整，不被截断。
4. **跨文档一致**：所有数字口径以第三节锚点为准，避免召回错块导致答案冲突。

### 6.2 验证指标建议

验证时可统计：各文档字符数、块数、规则-例外共现组数（参照 `eval/results/chunk-upgrade/boundary-experiment.json` 的方法），对比 `policy_section` 与固定窗口分块在长文上的差异：

- **块数**：单篇在 512 字符软预算下应切分为多块（如退换货细则约 28+ 块），以暴露分块边界问题；
- **规则-例外共现率**：随机抽取规则-例外组，检查是否落在同一块；
- **表格截断率**：检查连续表格是否跨块被截断；
- **锚点召回一致性**：以第三节锚点数字提问，验证不会因召回错块给出冲突答案。
