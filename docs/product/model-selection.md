# 智能客服模型选择

会员端与管理端的客服对话区提供模型选择。主用本地 Ollama，另有手填本地模型名及云端 OpenAI 兼容 API 配置。

## 使用方法

1. 下拉选择本地默认或已安装的聊天模型；“刷新”重读 Ollama 元数据，不加载、下载或删除模型。
2. “设置”可输入已安装的模型名。向量模型不能用于聊天，后台会拒绝；新安装模型需刷新。
3. 云端配置填写模型名、公网 HTTPS 地址及 API Key。地址可为 `/v1` 基址或完整 `/chat/completions` 地址；当前只支持该兼容协议与 Bearer Key，其他厂商协议需适配。
4. 点击“应用设置”后，选择只影响当前页面提交的请求，不改变服务默认模型或其他会话。切换生成模型不会重新创建向量索引。
5. “测试连接”只发送固定测试文本、最多请求32个输出token；本地测试结束释放驻留。云端测试可能计费，不发送商城聊天或订单内容。本轮没有执行真实云端测试。

政策原文和工具直答通常不需要生成，界面会注明“本条未调用生成模型”。响应返回选定模型及实际成功调用的模型，避免把选择项误当成答案生成证据。正常任务的规则、身份校验、确认与幂等流程不随模型切换改变。

API Key 仅存在于页面及本次服务请求内存，不进入浏览器长期存储、会话历史或模型列表；会员端离开页面清空云端选择和Key。云端错误不返回原始供应商错误体，已知Key的直接回显会被遮蔽。不要把真实密钥粘贴到聊天消息或实验记录里。

本地模型加载前使用“磁盘大小加额外余量”的保守内存估算，预留机器内存；它不是准确的驻留测量，可能保守拒绝。当前设备可用内存不足时，连接测试会返回503和明确提示，不强行加载。已有权重保留。云端地址会校验HTTPS及公网解析，禁用重定向；这不构成对任意供应商的信任背书。

## 接口与验证

- `GET /api/v1/models`：本地模型元数据及服务默认模型；能力读取来自 Ollama `/api/tags` 和 `/api/show`。
- `POST /api/v1/models/test`：仅做固定文本的短回复试测。
- `POST /api/v1/chat`：可选 `modelConfig`，字段为 `provider`、`model`、`baseUrl`、`apiKey`。

模型上下文按请求隔离并在结束后清理。Ollama回答缓存按模型隔离；自定义云端请求不复用回答缓存或共享默认模型熔断状态。模型列表及固定试测可由访客访问，知识写入和私有业务接口仍受保护。
